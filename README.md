# xtier_86kd：8 × RTX PRO 6000D（84GB）DeepSeek-V4.1-Flash 全栈推理加速与实测

本项目记录并公开了在 **8 × NVIDIA RTX PRO 6000D 84GB（Blackwell SM120，总显存 `669 GB`，双路 Xeon 6737P + 1 TiB DDR5 + 无 NVSwitch / 无 PCIe Switch）** 上部署 **`DeepSeek-V4.1-Flash-1017` + `DSpark`** 的全显存 `TP8 + Attention-DP8` 推理优化成果。

> **开源边界说明（Open-Core 展示仓）**：
> - **本公开仓库包含**：最终 Wave 4 全量 56 格（`8K → 1M × 1 → 64`）与 70 分钟真实 `@deepseek-ai/dsh` 编程压测战报、全部脱敏原始 JSON 数据、公开可复现的压测脚本（`bench/`），以及 [**五大核心支柱实现方法与关键算法伪代码（`docs/ARCHITECTURE.md`）**](docs/ARCHITECTURE.md)。
> - **保留闭源部分**：底层 SM120 CUDA/Triton 内核、零侵入运行时调度与通信钩子、DeepInfer 逐字节对齐补丁、10 形状 MXFP8 静态路由表以及生产网关与控制台源码保留在私有研发仓库中，本仓库不公开相关生产源码。

## 一、最终全量实测结果（Wave 4 生产默认栈）

> **核心指标与验证门禁**：
> - **显存与容量**：每卡权重仅 **`52.39 GiB`**，全局 FP4 主 KV 容量 **`108.29M` tok**（每 DP `13.54M`，少 99 GB 显存下反超市面 96G×8 方案 **`6.0×`**）。
> - **吞吐表现**：满载冷 Prefill 峰值 **`38,570 tok/s`**（`128K×64`，`2.43×`）；64 并发持续 Decode 窗口 **`5,415 tok/s`** / 稳态全重叠 **`6,492 tok/s`**（`8K–128K @ 64` 均值反超市面 96G×8 **`+85.9%`**，峰值 **`+91.1%`**，并独占通关 `512K×64`、`1M×32`、`1M×64` 三大爆池禁区）。
> - **精度与稳定性**：完全对标官方 DeepInfer 量化语义，3 段代码 PPL = **`2.0736`**（相对原生偏差 `+0.279%`，远优于 `±0.5%` 红线）；768 tok 贪婪解码 SHA-256 **100% 逐位一致**；内部真机 CUDA 单测 **`39/39` 全绿**；累计逾 5 小时全量 56 格 + 70 分钟 `dsh` 压测 **0 OOM、0 乱码、`cap len: 1.00` = `0 / 15,833` 批**。
